# 模拟面试小程序

这是一个功能简洁的微信小程序，旨在帮助用户通过模拟面试来提升求职技能。用户可以上传简历（模拟）、指定目标岗位，然后提供一系列面试问题。完成面试后，系统会生成一份包含综合评分、改进建议和详细问答回顾的总结报告。

## ✨ 功能亮点

- **模拟真实面试流程**：从上传简历到回答问题，体验完整的面试过程。
- **动态生成问题**：根据用户输入的目标岗位，动态生成相关的面试题目。
- **即时反馈与评估**：面试结束后，立即获得综合评分和针对性的改进建议。
- **面试历史追溯**：自动保存每一次的面试记录，方便用户复盘和跟踪自己的进步。
- **详细问答回顾**：可以查看每一次面试中自己的回答和题目的参考思路。
- **清爽直观的界面**：简洁的设计，让用户可以专注于面试本身。

## 🚀 如何使用

1.  **环境准备**：
    *   下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
    *   在开发者工具中导入本项目。

2.  **开始面试**：
    *   在首页，点击上传简历区域（此处为模拟操作，仅需输入简历名称）。
    *   在输入框中填写你想要面试的岗位，例如“前端工程师”。
    *   点击 **“开始模拟面试”** 按钮。

3.  **进行面试**：
    *   根据屏幕上显示的题目，在文本框中输入你的回答。
    *   点击 **“下一题”** 继续，直到回答完所有问题。

4.  **查看报告**：
    *   面试结束后，页面会自动跳转到总结报告页。
    *   在这里，你可以看到本次面试的综合评分、改进建议以及所有问题的回答详情。

5.  **回顾历史**：
    *   在首页，点击 **“查看面试历史”** 按钮。
    *   历史列表会展示你过往的每一次面试记录。
    *   点击任意一条记录，即可查看该次面试的完整总结报告。
    *   你也可以在历史页面点击 **“清空历史”** 来删除所有记录。
